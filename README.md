# SameFolderOnly

A Windhawk mod inspired by macOS Finder. When an app opens a folder that's already open, SameFolderOnly can reuse the existing File Explorer window instead of opening a duplicate. "Show in folder" can also highlight the requested file.

**Latest source:** [SameFolderOnly v4.1.6](mods/xandriw-explorer-select-interceptor.wh.cpp)

**Official Windhawk listing:** [SameFolderOnly](https://windhawk.net/mods/xandriw-explorer-select-interceptor)

**Published source:** [ramensoftware/windhawk-mods](https://github.com/ramensoftware/windhawk-mods/blob/main/mods/xandriw-explorer-select-interceptor.wh.cpp)

The published version lives in the Windhawk repository. Future official updates need a pull request to `ramensoftware/windhawk-mods`. This repository is the standalone source and maintenance home for SameFolderOnly.
